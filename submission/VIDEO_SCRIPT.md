# 3–5 minute walkthrough script

**0:00–0:25 — Intro**  
“This is Ajaia Docs, a lightweight team document workspace. I focused on the core loop rather than trying to recreate all of Google Docs.”

**0:25–1:20 — Create and edit**  
Show dashboard, create a document, rename it, type a short paragraph, apply bold/italic/heading and a bulleted list. Wait for the Saved indicator.

**1:20–1:50 — Persistence and import**  
Refresh the page, reopen the document, and show content remains. Import a small `.md` or `.txt` file and show it opens as a new editable document.

**1:50–2:50 — Sharing**  
As Disha, open Share and invite `aarav@ajaia.demo`. Switch to Aarav using the account selector. Show the document under Shared with me and open it. Mention that the API checks owner/shared access and only owners can manage grants.

**2:50–3:40 — Engineering choices**  
Explain React/Vite, Express, SQLite, the schema, persistent Render disk, and automated API test. Show README and test output briefly.

**3:40–4:15 — Tradeoffs and AI**  
Call out demo-only identity, TXT/MD-only import, no simultaneous editing, and why those were cut. Explain honestly which AI tools helped and what you manually reviewed/changed.
